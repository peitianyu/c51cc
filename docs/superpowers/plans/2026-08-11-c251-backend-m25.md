#   MOV Rm,@WRj   7E (j/2)2?  字节间接读
#   MOV @WRj,Rm   7A (j/2)2?  字节间接写
#   MOV WRj,@WRj  7E (j/2)6?  字间接读
#   MOV @WRj,WRj  7A (j/2)6?  字间接写

- [ ] **步骤 2：指针值装载**

- [ ] **步骤 3：LOAD 间接路径**

`v9: int = load v8`（v8 是 ptr 值，非 ADDR 产物）→ 把 ptr 值装载到 WRk → `MOV WRj,@WRk`（16 位间接读）。
- 查 value_to_addr 失败（非 ADDR 产物）→ 走间接路径
- ptr 值宽度：指针 16 位（near 指针）；far 指针 M3

- [ ] **步骤 4：STORE 间接路径**

`store v13, v7`（v13 是 ptr 值）→ 装载 ptr 到 WRk → 装载值 → `MOV @WRk,WRj`。

62_power 递归 + exp/2 除法：`c251_alloc_spill` 按值名键控静态槽——递归时同一值名多层共用同一地址，内层覆盖外层活值。
```bash

```

- [ ] **步骤 2：spill 栈式分配**

方案：**调用点把 spill 槽视作栈**——递归函数中，跨调用活跃的 spill 值在调用前 PUSH 到真栈（SP），调用后 POP 回槽。或：spill 槽本身改为栈偏移（每次调用分配新槽位）。
M2.5 简化（正确性优先）：**函数入口把参数槽/局部 spill 区整体下移**——用 SP 动态分配每调用帧的 spill 区（`MOV SP,#frame_end` 已硬编码 0xDF——改为函数 prolog 计算 `SP -= frame_size`，epilog `SP += frame_size`）。这同时解决 SP 硬编码问题（M3 项提前）。
参考 Keil：函数 prolog 调整 SP 到局部区之下。

- [ ] **步骤 2：BR 标志直传**

- BR 的条件值若定义于**紧邻的比较指令**（EQ/NE/LT/GT/LE/GE）且中间无其他标志修改指令 → 直接用比较的 CMP + 条件跳转

- 简单版：BR 的条件值 v，查其 def 指令 op；若是比较类且该 CMP 刚发射（无标志干扰）→ 发射对应 Jcc + 跳转

### 62_power 根因
DIV 指令将商放 WR2、余放 WR6。递归调用后：
1. LCALL → WR6 = half
2. MOV __spill_6 WR6 (保存 half)
3. POP 恢复 spill 槽
4. MOV WR6 __spill_6 (恢复 half)
5. DIV WR2,WR4 (第 2 次 DIV 计算 exp%2) → **WR6 被覆盖！**
6. L8 (奇分支) 用 WR6 做 half*half*base → 用余数代替 half

修复方向: 第 2 次 DIV 前把 half 保持到其他 WR 或槽，DIV 后再加载。
