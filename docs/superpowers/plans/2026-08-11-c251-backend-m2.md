**目标：** 完成 C251 后端核心指令集：真实寻址（ADDR/LOAD/STORE + dir16 + 符号解析）、值溢出（EDATA 临时槽 + liveness）、比较与条件跳转（CMP WRj + JE/JNE/JG/JLE 族）、分支控制流（JMP/BR/SELECT/PHI）、函数调用（LCALL + 参数传递）、位运算/移位/转换/NEG/DIV/MOD。验收 = `test/execute` 216 个测试经 sim251 跑通 + `keil_size_compare.py` 启动。


确认：`obj.h` 已有 `RELOC_ABS16`。M2 编码器对 `MOV Rm,SYMBOL` / `MOV dir16,SYMBOL` 形态：先发占位字节（0x0000），调用 `obj_add_reloc(obj, sec_idx, offset, RELOC_ABS16, symbol, 0)`；链接/编码后遍历 relocs 解析符号值（参考 c51 如何解析函数符号地址——c51 的 CALL 目标直接内联符号名，M2 采用同样方式：**编码时查 obj symbols 表解析符号值**，不引入链接器 reloc 阶段；两遍编码：第一遍收集符号偏移，第二遍填充）。

- [ ] **步骤 2：编码器加 dir16 形态（对照 functional.py）**

```c
/* 新编码（functional.py 权威）：
 *   MOV Rm,dir16    7E m3 hi lo
 *   MOV dir16,Rm    7A m3 hi lo
 *   MOV dir16,#imm  75 m3 hi lo lo?  —— 确认 functional.py 形态（MOV dir8,#v=75 d v）
 *   MOV dir16,WRj   7A (j/2)3 hi lo
 *   MOV WRj,dir16   7E (j/2)3 hi lo
 *   MOV A,dir16      E5 hi lo (A 相关, 251 用 dir16)
 */
```
在 `encode_instr` 的 MOV 分支扩展：a1 或 a2 是符号名（非 `#`/`R`/`WR` 开头）→ dir16 形态；符号地址两遍解析：
1. 第一遍：遍历 obj sections 构建符号→地址映射（obj_add_symbol 时 value 记录 section 内偏移；地址 = section 基址 + value）
2. 编码 MOV 时查映射：已知 → 直接填 hi/lo；未知（外部符号）→ 发 0x0000 + obj_add_reloc
3. 链接后（c251_gen 末尾）：遍历 relocs 填充

### 任务 2：ADDR/LOAD/STORE 真实寻址（全局变量）

**文件：**
- 修改：`src/core/c251/c251_isel.c`

- [ ] **步骤 1：ADDR isel**

SSA 形态（03_global_vars 实测）：`v1: ptr = addr @g_c` —— ADDR 的符号名在 `ins->labels[0]`（"@g_c" 或 "g_c"，去除 '@' 前缀）。M2：ADDR 生成一个"指针值"——记录 value→符号名映射（`value_to_addr` dict，c251_gen.h 增加），不真正生成代码（M2 简化：地址在 LOAD/STORE 时直接展开）。

```c
case IROP_ADDR: {
    /* 符号名在 ins->labels[0]，去 '@' 前缀 */
    const char *sym = ins->labels && list_len(ins->labels) > 0
        ? (const char*)list_get(ins->labels, 0) : NULL;
    if (sym && sym[0] == '@') sym++;
    if (sym) { /* 记录 value_to_addr: dest -> sym */ }
    /* M2: 不生成代码，地址在 LOAD/STORE 展开 */
    break;
}
```

- [ ] **步骤 2：LOAD isel（全局符号）**

```c
case IROP_LOAD: {
    /* ptr 是 ADDR 产物 → 查 value_to_addr 得符号名 → MOV WRj,SYMBOL */
    ValueName ptr = src1_of(ins);
    char *sym = value_to_addr_lookup(ctx, ptr);
    int wr = isel_alloc_wr(ctx, ins->dest);
    if (sym) {
        isel_emit(isel, "MOV", wr_name(wr), sym);   /* 编码器 dir16 形态 */
    } else {
        /* 指针变量/数组元素 → M2 简化: 先支持全局符号直访；其余报错提示 */
        fprintf(stderr, "c251 isel: LOAD 指针寻址 M2.5 支持 (v%d)\n", ptr);
    }
    break;
}
```

- [ ] **步骤 3：STORE isel（全局符号）**

```c
case IROP_STORE: {
    /* store ptr, val → MOV SYMBOL,WRj */
    ValueName ptr = src1_of(ins), val = src2_of(ins);
    char *sym = value_to_addr_lookup(ctx, ptr);
    int r = isel_value_reg(ctx, val);
    if (sym && r >= 0) isel_emit(isel, "MOV", sym, wr_name(r));
    else if (sym && !r) fprintf(stderr, "c251 isel: STORE 值未物化\n");
    break;
}
```

- [ ] **步骤 2：溢出路径（isel）**

`isel_alloc_wr` 返回 -1（寄存器不足）时：
- LOAD 值：`MOV WRj,SPILL_SYMBOL`（符号名 `__spill_N`）

### keil_size_compare（Keil C251 O9 SIZE 实测，suite 前 19 个）
| 类别 | c251cc/Keil | 说明 |
|------|-------------|------|
| 常量折叠（00-09） | 36-42% | c251cc 更优（fold 成 MOV WR6,#imm + RET） |
